口径说明（必须一起看）：
1. 入场 = 分析日之后第一个交易日收盘；分析在 15:30 后完成，T+1 收盘是可执行近似。
2. 个股收益用前复权收盘价（含现金分红）；基准用价格指数（不含分红），因此超额收益会略偏高，不能当作精确的超额。
3. N 是分析条数，stocks 是去重股票数。同一只股票被反复分析、窗口重叠时会重复计数，不能把 N 当独立样本。
4. 未到期或基准缺该交易日行情时保持 NULL，不填 0、不插值。首次算出的非空值已冻结，不随后续复权重算。
5. 命中率只对方向性信号有意义：BUY 跑赢 = 命中，AVOID 跑输 = 命中；HOLD 不评命中率。
