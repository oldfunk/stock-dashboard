# AI Berkshire 对齐计划

## 目标
将我们的 AI 分析深度提升到 AI Berkshire 级别（甚至更好），通过：
1. 结构化 5 类护城河评估
2. 管理层资本配置量化分析
3. Owner Earnings 估值区间估算

**原则：不改流水线结构，全部在 Prompt + 数据预处理层完成。**

---

## Phase 1: 数据预处理 — 给 LLM 喂更好的数字

**改动文件：** `ai_analyzer.py` 的 Prompt 构造部分

从现有 financial_history 计算并传入新指标：

| 新指标 | 计算方式 | 含义 |
|---|---|---|
| 回购/稀释年均率 | share_dilution_10y / 10 | 正=稀释 负=回购 |
| FCF 收益率 | fcf_5y_sum/5 / 市值 | 跟国债比 |
| ROE - ROIC 差 | roe_5y - roic_5y | 大=用杠杆撑ROE（危险） |
| 营收 CAGR | financial_history 最近5年营收复合增速 | 增长质量 |
| 净利稳定性 | 5年净利变异系数 | 波动越小越稳 |

**工作量：** 3 个 helper 函数，~40 行

**风险：** 低。全是从已有 financial_history 算的。

## Phase 2: Prompt 重构 — 三项异步推进

**改动文件：** `ai_analyzer.py` 的 ANALYSIS_PROMPT

### 2a. 护城河清单评估
将原来的一句"凭什么不被干掉"拆成 5 项逐一判断：

- 转换成本：换供应商的代价/时间
- 网络效应：用户增长对价值的影响
- 无形资产：品牌溢价/专利保护/许可壁垒
- 成本优势：规模/区位/工艺领先
- 有效规模：市场自然寡头

每项要求 LLM 输出判断 + 证据 + 趋势（变强/变弱/稳定）。

**难点：** 有些护城河没有可传递的数据（如转换成本），全靠 LLM 的知识。但这正是 LLM 的价值所在。

### 2b. 管理层资本配置
要求 LLM 分析：

- 再投资回报：留存利润产生了多少新增价值？（看 ROIC 趋势）
- 回购纪律：股份是在低位还是高位减少？（看 PE 区间 vs 回购时间）
- 并购历史：商誉/资产比变化
- 激励对齐：股权激励是否合理（看稀释率）

**数据支撑：** share_dilution 趋势、ROIC 趋势、FCF 趋势、市值变化

**难点：** 精确的回购/增发时间点不可得。LLM 只能用年度稀释率做定性判断。

### 2c. 内在价值估算
要求 LLM 做三档 DCF 区间：

- Owner Earnings ≈ 净利 + 折旧 - 维持性资本开支
- 保守：0% 增长，折现率 10%
- 基准：3% 增长，折现率 8%
- 乐观：5% 增长，折现率 6%

然后跟当前市值对比，得出安全边际幅度。

**难点：** 维持性 vs 增长性资本开支无法区分。近似处理：用过去 5 年平均 FCF 作为 Owner Earnings 代理。

---

## Phase 3: 验证 + 迭代

1. 用新 Prompt 重新跑 20 只股票的全量 AI 分析
2. 抽样检查分析质量（护城河判断是否合理？估值区间是否靠谱？）
3. 如有明显质量问题 → 调整 Prompt 措辞再跑
4. 用户评审后定稿

**预期时间：** 20 只 × ~1.5min/只 ≈ 30min

---

## 何时应该停下来汇报

- Phase 1 的数据可用性检查：如果关键指标无法从现有数据算出 → 汇报
- Phase 2c 的 DCF 估算：如果 LLM 算出来的估值区间与市值差异过大（偏差 >100%）→ 汇报
- Phase 3 验证：如果连续 3 只股票的分析明显不如现有版本 → 汇报
