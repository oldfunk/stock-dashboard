而是 risk_off 环境本身的均值回归暴露"。本件按只读方式把这句话算成数字。

## 结论（三条，按重要性）

1. **T+60 与 regime 完全共线**：148 个成熟行里 risk_off 147 + 无标签 1，
   **可作对照的非 risk_off 成熟行 = 0**。所以那 17.05pp 里"MOS 贡献多少"
   在现有数据下**不可归因**——不是嫌疑，是没有对照。
2. **扣掉环境基线后，MOS 的净增量只剩约 3pp（且只有 T+60 有）**：
   同在 risk_off 内、相对 `<=0` 档（16 只票 96 行，自身超额就有 **14.04pp**）：
   ≥40 档 **+3.01pp** [+0.67, +5.36]，T+20 口径 **-0.06pp** [-2.52, +2.32]（CI 跨 0）。
   即环境基线占首跑数字的 **82%**（14.04 / 17.05）。
3. **样本与选股混在一起**：≥40 档只有 **6 只票 / 45 行 / 20 个交易日**，
   与基线档的股票**重叠 0 只**——同 regime 内的档间差同时也在比"不同的公司"。
   个股层面 T+60 均值：002648 21.95 / 600398 15.18 / 601600 14.20 / 603233 7.91pp，
   四只里三只都高于基线档均值，这 3pp 更像是"这几只票赶上了反弹"。

## 对首跑结论的影响（不改实验、不改库，只提处置建议）

`E-H001` 的 `supported` 是**按预注册判据正确得出**的（主指标 `excess_60_>=40 > 0`
且 CI 不含 0），问题在解释层：那条判据没有要求"同 regime 内有对照"，
所以在成熟样本 100% 落在 risk_off 的情况下，它衡量的是
**"高 MOS 股在 risk_off 期的超额"**，而不是"MOS 的预测力"。建议：

1. **H-001 状态保持 supported，但结论口径改一行**：把"方向 supported"限定为
   "risk_off 环境内成立"，避免后续文档引用 17.05pp 当 MOS 效应。
2. **H-002 用同 regime 对照做主判据**（本工具已经给出算法）：
   主指标建议 = `neutral` 环境下 `excess_20(>=40) - excess_20(<=0)`，
   前提是母方决定接受 14 行 / 3 只的样本量；否则就得等样本长大。
3. **等自然成熟即可，不必造数据**：10—11 月的 neutral 期分析到 12 月就有
   非 risk_off 的 T+60 成熟行，届时 `excess_60` 的共线标记会自动解除——
   这条是本结论最硬的落地方式：**先补分析量，再谈 MOS**。
   （现有 390 行分析集中在 7—9 月，本身就限制了任何跨 regime 检验。）
4. 若要按股票配对（消除"比的是不同公司"）：同一只票在不同时点的 MOS 会变档，
   现库 `>=40` 与 `<=0` 档股票零重叠，所以**目前无法配对**；
   等 `>=40` 档出现 ≥2 只票同时有 `<=0` 档分析行时才可行。

## 方法与已知局限（如实记）

- CI 用**按股票分块**的 bootstrap（一只票常有十几行到期，按行重抽样会把有效
  样本夸大十几倍）；两组各自独立重抽样后取差，是常见的保守近似。
- 差值 CI 我取的是"两组独立 bootstrap 的端点差"，比配对/置换检验略保守（偏宽）。
- **本件第一版把 `excess_*` 又乘了 100**：该列存的已经是百分点
  （601600 T+20 = 23.26 → 23.26pp），所以首版数字放大了一百倍。
  修正后所有 pp 数字与实验输出同量级（母方报 17.05 / 13.90，本工具算出
  17.05 / 14.04，差异来自 ≤0 档是否含无标签行）。这个坑记在这里，
  免得下一次有人在别处再乘一次。
- 无 regime 标签的 2 行不参与分档均值（`tier_regime_means` 要求 regime 非空），
  共线判定也不把它们算作对照。
