# 单股详情页迭代路线

> 起始：2026-07-22
> 基线：单股详情页 12 章节已上线（AI 笔记 + 动态财务历史横向滚动 + 时间线 + 在池状态），第 10 章节为技术分析扩展位占位。

## 已有数据底座

`src/collector/akshare_fetcher.py` 已接入：
- 实时行情（`stock_zh_a_spot`）
- 业绩报表（`stock_yjbb_em`）
- 财务摘要（`stock_financial_abstract_ths`）
- 利润表（`stock_profit_sheet_by_report_em`）
- 现金流表（`stock_cash_flow_sheet_by_report_em`）

akshare 原生还支持 K 线、资金流向、龙虎榜、行业板块、F10 等，扩展成本低。

## 设计模式约束（已固化到 project_memory）

- **宽表格**：横向滚动容器 + `width: max-content` + 第一列 `position: sticky` + `white-space: nowrap` + 父容器 `overflow-x: hidden`
- **多卡片 grid**：卡片 `min-width: 0; overflow: hidden` 防止撑开列宽
- **LLM JSON 字段**：写模板前必须查 DB 确认实际字段名
- **零依赖优先**：评分趋势用纯 SVG 生成，不引入前端库（除非确有必要）
- **pi 性能**：数据定时缓存，非实时拉取；复杂渲染评估 CPU/内存负载

## P0 — 行情核心（用户体验提升最大）

### ① K 线图（日K/周K/月K）
- **接口**：`ak.stock_zh_a_hist()`（已现成）
- **展示**：日K 蜡烛图 + 成交量柱，支持切换日/周/月
- **前端方案**：纯 SVG（延续无依赖方案）或引入轻量 K 线库
- **缓存**：定时拉取缓存到 SQLite，避免每次访问详情页都打 akshare
- **状态**：进行中

### ② 技术指标（MA/MACD/KDJ/RSI）
- **数据**：从 K 线收盘价本地计算，无需新接口
- **展示**：K 线下方叠加 MA 均线 + 独立指标面板
- **依赖**：需先完成 ① K 线图

---

## P1 — 资金与博弈（中阶，看主力动向）

### ③ 资金流向（主力净流入）
- **接口**：`ak.stock_individual_fund_flow()`
- **展示**：近 N 日主力/超大单/大单/中单/小单净流入柱状图 + 累计曲线
- **成本**：中（新接口 + 新表 + 渲染）

### ④ 龙虎榜
- **接口**：`ak.stock_lhb_detail_em()`
- **展示**：上榜日期 + 买卖席位 + 净买入
- **注意**：数据稀疏，仅上榜日有数据

---

## P2 — 结构化对比（高阶，决策辅助）

### ⑤ 行业对比
- **接口**：`ak.stock_board_industry_*()` + 同行业 PE/ROE 排名
- **展示**：本股在同行业中的 PE/PB/ROE/增速 排名条
- **成本**：中高（需建立行业映射 + 批量拉同行业数据）

### ⑥ F10（股东/高管/分红/增持）
- **接口**：`ak.stock_individual_info_em()` + 多个子接口
- **展示**：十大股东、高管变动、分红历史、限售解禁
- **成本**：高（多个接口 + 多张表）
