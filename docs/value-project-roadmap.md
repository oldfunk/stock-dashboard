## 1. “价值投资项目完成”的定义

这里的“完成”不是实盘接管，而是满足以下六条，能拿真实数据连续运行、能解释、能复盘：

1. **数据可信**：活跃 A 股覆盖 ≥99%，关键财务/价格/估值字段有明确缺口清单；每日数据新鲜度可验证。
2. **分析可信**：20 只候选的估值可复现；AI 结论有来源、无买卖建议、可评估；MOS/前向收益可追踪。
3. **纸盘可度量**：连续 8 周自主运行，NAV 每日有行；周度归因/费用/回撤/听话率可出表。
4. **研究闭环**：R0–R6 至少跑通一条“市场状态→假设→实验→策略→部署→归因→决策”的完整链，可复现。
5. **产品可用**：日报/周报、绩效页、新闻检阅、研究页、巡检脚本可用；备份/恢复有演练。
6. **接管准备就绪**：写死接管门槛与评估方法，但**不接真实账户、不下真实单**。

## 4. 已定口径 / 待你确认的四件事

1. **2026-10 分析缺口：重建，但标记为“重建”**
   - 10 月有 **23 个 screening run / 460 行**输入；`stock_analysis_history` 无原始 AI 文本。
   - 做法：隔离库重建（先 23×Top5=115 只，预算允许再全量），标记 `reconstructed=20261128`；
   - 边界：当前模型知道未来，重建结果**不用于策略前向收益/绩效归因**，只用于时间线完整性和研究叙述。
2. **`pe_percentile_5y`：5 年、年报 EPS（静态 PE）、PIT 披露日、全市场 PE 中位数**
   - 不用 PE TTM：`financial_history` 只有年报 EPS，5 年季度 TTM 序列不存在；用当前 TTM 无法回看。
   - 与个股 `valuation_percentile.py` 同口径；负 EPS 不计；覆盖 <60% 不输出。
   - 10 年作为参考列，不替代 5 年主列。
3. **13 只无 K 线活跃股：先查清，再决定 100% 还是白名单**
   - 优先确认是否停牌/退市/新上市/源缺失；能补则补。
   - 若上游确无，写白名单并标注“无 K 线原因”，不硬凑 100%。
4. **R4 LLM 研究助手：先做 R4-lite，不做全量**
   - 只读工具 + 一个任务（实验复核或决策备忘录）+ golden cases + 引用校验；
   - 不给写权限、不自动改策略；等数据/纸盘 8 周样本稳定后再评估扩展。

## 5. 明确不做（本阶段）

- 不接真实券商/真实账户、不自动下真实单；
- 不做高频/日内规则、不做杠杆/衍生品；
- 不扩新策略、不做移动端/大改 UI；
- 不用新闻直接触发交易；
- 不在未验证的数据上做参数优化。

## 6. 节奏与门

- 每周一–周五：只观察 A2/F1/B1 与纸盘，不改策略参数；
- 每周六：数据回填/实验/文档/周报；
- 门 G1：A2 3 日 + 数据覆盖 ≥99% → 进 Q2；
- 门 G2：B1 10 日 + 归因连续 4 周 → 进 Q3；
- 门 G3：R6 一条链可复现 → 准备 v2.3/v2.4；
- 门 G4：六条完成定义全满足 → 宣布“模拟盘阶段完成”，再讨论接管。
