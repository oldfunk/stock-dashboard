# 单股详情页设计

> 在 AI 观察池 5 只股票 + 候选股 25 只股票的卡片上点击，进入单只股票的专注详情界面。
>
> 一次看完这只股票的全部信息：关键指标快照 → AI 投资笔记 → 护城河 / 管理层 / 内在价值 / 交易策略 / 逆向思考 → 动态财务历史 → 历次 AI 分析时间线 → 在池状态。
>
> 无 AI 分析时降级为"纯数据版"（财务 + 行业 + 估值），不依赖新增表或实时 LLM 调用。

## 背景与动机

当前首页 AI 观察池和 /candidates 短期交易区都是"卡片网格"视图——一眼扫完，但每只股票的信息都被压缩进一张 ~180px 宽的卡片。用户需要"点进去专注看一只股票的全部信息"的能力，参考 AI Berkshire 项目的单股笔记阅读体验。

## 目标

1. **专注阅读** — 单栏叙事流（C 方案），顶部一行关键指标快照条，然后按"决策→叙事→结构化指标→时间线"顺序自上而下阅读。
2. **无 AI 也能看** — 没有 AI 分析的股票仍能查看完整财务指标 + 行业 + 估值（"纯数据版"）。
3. **历史可追溯** — 历次 AI 分析按时间线排列，含评分趋势小图。
4. **扩展性强** — 预留"技术分析扩展位"（K 线图 / 技术指标 / 资金流向 / 行业对比 / F10 等专业数据），后期参考东方财富、同花顺陆续补全。
5. **零依赖增量** — 不新增表、不调 LLM、不引入前端依赖。

## 非目标

- 本次不做 K 线图、技术指标、资金流向等行情类数据
- 不改动钉选股票、搜索结果页的交互
- 不做实时 LLM 分析（只展示已入库的历史分析）
- 不引入 echarts / chart.js 等前端图表库（评分趋势用纯 SVG 生成）

## 路由与入口

### 新路由

```
GET /stock/{code}  →  stock_detail.html
```

`code` 为 6 位 A 股代码，如 `000792`、`688648`。

格式校验：
- 长度 6，全数字
- 不匹配则返回 404（避免无效查询打 DB）

未在 `stock_snapshot` 中找到也返回 404。

### 入口范围

| 位置 | 是否可点 | 说明 |
|---|---|---|
| 首页 AI 观察池 5 张卡片 | ✅ | 整张卡片可点 |
| /candidates 短期交易区 25 张卡片 | ✅ | 整张卡片可点 |
| 钉选股票列表 | ❌ | 保持现状，不在本次范围 |
| 搜索结果 | ❌ | 保持现状 |

### 卡片交互

- 整张卡片可点 → `onclick="location.href='/stock/{{ stock.code }}'"`
- hover 状态：`cursor:pointer` + 轻微高亮（`background` 变化）
- 卡片内部已有的按钮（如"钉选"）点击不触发跳转：`event.stopPropagation()`

### 返回

- 顶部 `<a href="/">← 返回看板</a>`
- 浏览器后退原生支持

## 数据来源

全部使用已有表，无需新增表或字段。

| 章节 | 数据源 |
|---|---|
| Header（名称/行业/现价） | `stock_snapshot` + 实时行情缓存（`get_realtime_cache()`） |
| 关键指标快照条 | `stock_snapshot`（PE/PB/ROE/营收增长/利润增长/市值/资产负债率/股息率） |
| 投资人笔记 | `stock_analysis_history.ai_analysis` 最新一条的 `analysis` 字段 |
| 护城河评估 | 同上的 `moat_evaluation` 字段（5 维度数组） |
| 管理层评分 | 同上的 `management_score` 字段 |
| 内在价值 | 同上的 `intrinsic_value` 字段 |
| 交易策略 | 同上的 `trade_strategy` 字段（Signal/买入区/目标/止损/置信度） |
| 逆向思考 | 同上的 `reverse_thinking` 字段 |
| 动态财务历史 | `financial_history` 表（所有年报/季报） + `financial_summary` |
| 历次 AI 分析时间线 | `stock_analysis_history` 全部记录（按日期倒序） |
| 在池状态 / 调入理由 | `ai_watchlist`（如在池）+ `ai_watchlist_history` |

## 页面结构（单栏叙事流）

### 1. Header

```
[← 返回看板]

盐湖股份   000792 · 化工原料               ¥18.42  +2.34%
                                                  [HOLD]  [评分 78]
```

- 名称（大字）+ 代码 + 行业（灰色小字）
- 右侧：现价 + 涨跌幅（红涨绿跌）
- Signal badge（BUY/HOLD/AVOID，只在有 AI 分析时显示）
- 评分 badge（如已分析）

### 2. 关键指标快照条

一行 6-8 个关键指标，始终显示（来自 `stock_snapshot`）：

```
PE 12.5 | PB 2.1 | ROE 18.3% | 营收增 +15% | 利润增 +20% | 市值 980亿 | 负债率 35% | 股息率 2.1%
```

- 每个指标：label（小灰字） + value（大字）
- 值为空显示 `--`
- 这一行保证"无 AI 分析也能立刻看到关键数据"

### 3. 投资人笔记（如 `ai_analysis.analysis` 存在）

- 章节标题：`投资人笔记`
- 整段叙事文本（多段），左侧 accent border 装饰
- 字段为空 → 整段隐藏

### 4. 护城河评估（如 `moat_evaluation` 存在）

5 个维度，每行：

```
转换成本       ●●●○○  稳定   evidence...
网络效应       ●○○○○  稳定   evidence...
无形资产       ●●●●○  改善   evidence...
成本优势       ●●●●●  稳定   evidence...
有效规模       ●●●●○  稳定   evidence...
```

- 1-5 分用实心圆 / 空心圆表示
- trend 用文字（稳定/改善/恶化）
- evidence 是说明文本

### 5. 管理层评分（如 `management_score` 存在）

```
资本配置能力       8/10
股东友好度         7/10
                    [总结：1-2 句话]
```

### 6. 内在价值 + 安全边际（如 `intrinsic_value` 存在）

```
保守估值     950 亿
基准估值    1200 亿   ← 高亮
乐观估值    1500 亿
安全边际      +22%
方法          Owner Earnings × 10倍
```

- 基准估值高亮显示
- 安全边际正值绿色，负值红色

### 7. 交易策略（如 `trade_strategy` 存在）

```
Signal: HOLD    置信度: 中
买入区间: 17.5 - 19.2
目标价:   23.0
止损价:   15.8
持有周期: 中期（3-6 月）
```

- Signal 大字 + 对应颜色 badge

### 8. 逆向思考（如 `reverse_thinking` 存在）

```
什么情况下这家公司会死？
1. 锂价长期低迷（>3 年）...
2. 盐湖提锂技术被颠覆...
3. 环保事故导致停产...
```

### 9. 动态财务历史（如 `financial_history` 有数据）

**不绑定 5/10 年固定数字**，按公司实际有数据的年数动态展示。

数据源：`financial_history` 表的所有年报记录 + `financial_summary` 衍生指标。

展示：
- 数据覆盖区间（如 "2020-2026"）
- 关键指标趋势：ROE / 毛利率 / 净利率 / 营收增长 / 利润增长 / OCF/股 / FCF / 股本稀释 / ROIC
- 每个指标一行：`ROE  12.3% → 15.2% → 18.1% → ...`
- 评判标准：与历史自身对比（趋势 / 同比 / 波动），不固定阈值
- 衍生汇总（来自 `financial_summary`）：ROE 5y/10y avg、ROE 波动率、ROE 改善、FCF 累计等

无数据 → 整段隐藏。

### 10. 技术分析扩展位（预留）

  <!-- 后期参考东方财富、同花顺陆续补全 -->

本次只预留位置和模板结构，不实现具体内容。后期开发时只需在占位区填入 echarts/akshare K 线组件或表格，无需改路由。

### 11. 历次 AI 分析时间线

来自 `stock_analysis_history` 表，按日期倒序：

```
2026-07-21  HOLD  评分 78   [本周复盘笔记...]
2026-07-14  BUY   评分 82   [上周复盘笔记...]
2026-07-07  BUY   评分 85   [首次入池...]
```

顶部加一个简单的评分趋势 SVG 折线图（无依赖，纯 Jinja 模板生成）：
- X 轴：日期
- Y 轴：评分
- 折线连接所有分析点
- 鼠标 hover 显示具体数值（原生 SVG title 属性）

无 AI 分析历史 → 显示"暂无 AI 分析历史"占位。

### 12. 在池状态（如在池）

来自 `ai_watchlist` + `ai_watchlist_history`：

```
在池状态：✓ 当前在池（在池 3 周）
调入日期：2026-07-01
调入理由：评分最高，盐湖资源龙头，护城河宽...

调入调出历史：
  2026-07-21  keep   评分稳定
  2026-07-14  keep   Signal 未变
  2026-07-07  add    首次调入
```

不在池 → 整段隐藏。

## 无 AI 分析的 Fallback

- 章节 3-8：检查 `ai_analysis` 字段，无数据则整段隐藏
- 章节 1-2：始终显示（来自 `stock_snapshot`）
- 章节 9（动态财务历史）：有 `financial_history` 数据就显示，否则隐藏
- 章节 11（历次分析）：空则显示"暂无 AI 分析历史"占位
- 章节 12（在池状态）：不在池则隐藏

**降级效果**：一只从未被 AI 分析过的股票，仍能看到完整的财务指标 + 行业 + 估值，作为"纯数据版"使用。

## 性能考虑（pi 环境约束）

- 所有数据来自 SQLite 本地查询，单次请求 < 100ms
- `financial_history` 单只股票通常 5-20 条记录，无性能压力
- `stock_analysis_history` 单只股票通常 1-10 条记录
- 不引入实时 LLM 调用，无并发风险
- 后期 K 线图等扩展需评估 pi 的 CPU/内存负载，根据实际情况决定是否实现
