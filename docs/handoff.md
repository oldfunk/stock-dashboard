- **`batch_save` 保留旧值**：上游新值为空时不再清空（防丢回填），代价是上游"确实删除"的值会陈旧；需要时可加显式清理入口。
- **`partial` 状态不会被默认重跑**：需要 `--retry-partial`；夜间 cron 不会自动补，文档已注明。
- **门禁仍有一次 flaky 记录**（测试隔离类）；权威门禁走生产 worktree，CI 仅记录。
- **生产 SSH 对连续建连敏感**：脚本必须限速；deploy.sh 已 1s 间隔。
- **回填与业务共用 SQLite（WAL）**：已 `busy_timeout=5000`；出现 `database is locked` 应降 `--limit` 或错峰。
- **静态 JS 改后必须升版本戳**（`/static/*.js?v=YYYYMMDDx`）。
