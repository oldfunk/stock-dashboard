# 收盘检阅与投资笔记融合（设计 v2，2026-11-24）

> 上游：用户方向与 2026-11-24 决策——
> ① **AI 自主出分析，不做人工确认**；② 纸盘只用母策略，**不接新闻**（政策变动可周度微调）；
> ③ 与纸盘联动只做**转接口**；④ 交易频率**不另设规则**，由母策略自然决定；⑤ 盘中只处理**重大突发事件**；
> ⑥ 纸盘 P&L/决策写进笔记，作为**变量分析**留档。
> 状态：设计定稿（v2）；先做 3 天离线原型，再进生产线。

## 1. 现状盘点（为什么现有新闻流不能用）

| 已有 | 位置 | 问题 |
|---|---|---|
| 新闻采集 | `src/collector/news_fetcher.py` | 7–23 点每 15 分钟轮询；`news_item` 599 条；有 code/summary/url/source/time |
| 舆情日报 | `src/analyzer/news_summarizer.py` → `news_digest`（18:30） | 偏短线/资金面（"牛散""融资客""短期调整压力"），无引用、无论点/红线关联 |
| 投资笔记 | `ai_journal` + `/journal` | 只有周度复盘 + 大盘解盘；与舆情日报两张皮 |
| 纸盘 | `paper_account.db`、`ai_journal` | 可提供 P&L/持仓/计划/成交，但没有只读转接口 |
| 面板 | `/journal` | 没有"收盘检阅"、没有来源、没有事件分级 |

**结论**：数据够，缺的是**价值视角的编排、实体关联、自主发布与低换手纪律**。

## 2. 定位（写死）

1. **AI 自主出结论，不设人工确认闸**。笔记直接发布（`published`），标注"AI 自主生成"；
   人可以事后批注/编辑，但不阻塞、不作为发布前提。所有结论带来源与版本，可审计。
2. **新闻不进入纸盘交易**。纸盘继续只走母策略（signal/buy_zone/stop）；
   政策/监管类变化只允许进入**周度策略复核**（微调参数），不触发盘中或次日交易。
3. **四问输出**：今天市场发生了什么（事实）→ 对我的持仓/观察池/候选意味着什么（影响）
   → 哪些论点/红线被触及（维护）→ 明天/下周要看什么（关注）。
4. **事实与解释分层**：事实带 `news_item.id + url + 时间`；AI 解读单独成段；
   来源缺失显式 `unavailable`，不拿旧闻冒充今日。
5. **无要闻是合法输出**："今日无影响级要闻"，不凑字数；相关性排序
   **持仓 > 观察池 > 候选 > 宏观**。
6. **交易不另设频率规则**：母策略正常出信号，AI 遵循即可；本项目交易频率本来就低，
   周报只做复盘，不影响交易。

## 3. 功能拆解（F 线）

### F1 收盘检阅（15:45 自动发布）

```
新闻入库（已有）→ 去重/聚类 → 实体链接（code/行业/主题）→ 相关性排序
→ 论点/红线匹配（watchlist_thesis）→ LLM 结构化事实表 + Markdown
→ 直接发布到 news_digest + ai_journal（status=published）→ 面板
```

- 时间：15:45 首跑，源晚到 18:30 重试；幂等按日期；同一天只更新 AI 版本，人工批注另存。
- 成本：每天 1 次（JSON + Markdown 两次调用），上限 30 条。
- 失败：某源不可用 → 标 `unavailable` + 原因；无新闻 → "今日无可用要闻"。

### F1.5 盘中重大突发事件（只提醒，不交易）

**只处理重大事件**，不做常规新闻流。分级与阈值（v1，可调）：

| 级别 | 判定（规则引擎先行） | 范围 | 处理 |
|---|---|---|---|
| **P0 政策/监管** | 官方源（国务院/证监会/交易所/央行/财政部/发改委/工信部/卫健委/医保局/住建部等）且命中：印花税/过户费/交易制度/T+0/涨跌停/减持新规/退市/注册制/IPO/再融资/降准降息/LPR/存款准备金/集采/价格管制/关税/出口管制/行业监管重大转向 | 全市场或持仓/观察池所属行业 | 面板提醒 + 事件条目；进入**下一次计划窗口的策略复核清单**（AI 可据此微调参数），不直接下单 |
| **P1 公司重大** | 立案调查/行政处罚/财务造假/审计非标/业绩预告转亏或同比降幅 ≥50%/重大资产重组/停牌/实控人变更/退市风险警示/重大诉讼/质押爆仓/实控人或 5% 以上股东大额减持 | 仅持仓/观察池/候选（按 code 实体链接） | 面板提醒 + 事件条目；进入下一次计划窗口的风险复核，不直接下单 |
| **P2 市场级** | 沪深300/上证/创业板日内 |涨跌| ≥3%（≥5% 升为 P0）；两市成交额较 20 日均值 ±50% | 全市场 | 面板提醒 |
| **不提醒** | 研报/评级调整、资金流、牛散、日常公告、行业综述、非持仓个股涨跌 <5% | — | 只进收盘检阅候选 |

- **规则先行、LLM 只做解释**：严重度由关键词/实体/指数阈值决定，避免模型漏判；LLM 只写一句"影响与待验证点"。
- **去重与限流**：同实体+同事件类型 30 分钟冷却；按新闻聚类去重；每日上限 P0 5 条、P1 10 条、P2 3 条。
- **只提醒，不交易**：事件写 `news_event`/`op_log` 与笔记；P0/P1 只进入**下一次计划窗口**的复核清单，
  下单仍走母策略的 signal/buy_zone/stop 与风控闸门；不存在"新闻触发下单"的路径。
- 提醒必须带：来源、发布时间、影响标的（可空）、事实/推断标记、事件级别。
- 阈值集中在配置（`news.event_thresholds`），改口径不改代码；先 dry-run 统计一周命中量再上线。

### F2 笔记融合（`ai_journal` 扩展）

每日笔记模板（AI 自动发布，可被人工批注）：

```
# YYYY-MM-DD 收盘检阅（AI 自主）
## 1. 市场事实（指数/成交/涨跌家数，带 asof）
## 2. 持仓与观察池（事实 → 影响 → 是否触及论点/红线）
## 3. 候选池（只列相关信息，不覆盖全部 20 只）
## 4. 组合变量（纸盘 NAV/持仓/本周计划与成交，来自只读转接口）
## 5. 纪律与风险（本周交易与计划、拒单、回撤；新闻不构成买卖指令）
## 6. 下周关注（≤3 条，可验证）
## 7. 来源（news_item id + url + 时间；缺失显式标注）
```

- 状态：`published`（AI 自主）→ 人工批注 `annotated`（可选，不阻塞）；
- 版本化：同一天多次运行保留 `updated_at` 与旧版本；人工编辑不被覆盖；
- 周度复盘读取本周笔记 + 纸盘变量，做聚合（不重复生成）。

### F3 检阅记录（不是人工闸）

- 记录"AI 已检阅"：要闻数、命中持仓数、红线触发数、来源失败数、生成耗时；
- 人工可对结论打标（同意/不同意/补充），作为后续评估数据；
- **没有任何"确认后才能发布/交易"的步骤**。

### F4 面板

- 首页"今日要闻"卡：Top 3，相关性优先，带来源；
- `/journal` 日视图：事实/影响分层、来源可点、与昨日 diff、周度聚合入口；
- 盘中 P0/P1 提醒条（仅重大事件），可展开事件条目；
- "无要闻"空态；来源失败状态可见。

### F5 评估（自主模式）

- 标注集：20–30 条真实新闻 × 相关性 + 红线；
- 指标：引用率（应为 100%）、相关性 precision ≥70%、**买卖建议出现次数=0**、
  P0/P1 事件漏报率（人工抽查）、笔记是否被人工大幅改写（编辑距离）；
- 离线脚本先跑 3 天真实数据，再上线；上线后每周抽检。

## 4. 与纸盘的转接口（只读）

- 复用 E0 桥：`src/paper_bridge` 读 `positions/nav/agent_plans/fills`，
  笔记只引用**已发生**的数据（NAV、成交、计划），不反向写策略；
- 纸盘决策由母策略决定，不另设节奏规则；P0/P1 事件进入**下一次计划窗口**的复核清单，不直接下单；
- 接口字段：`nav`、`positions`、`week_fills`、`pending_plan`、`rejects`；
  `asof/stale` 必带；失败降级为"无组合变量"。

## 5. 数据与架构

- 不新建第二套笔记系统：扩展 `ai_journal`（`note_type/status/sources_json/annotations`）；
  `news_digest` 加 `kind`（`sentiment|close_review`）；事件用 `news_event`（新增小表）或复用 `op_log`。
- `news_item` 增 `entities_json`、`cluster_id`（去重/实体链接）；能复用则不加表。
- 新模块：`src/news_review/`（normalize/link/rank/prompt/persist），web 只读渲染；
  不在路由里调 AKShare/LLM。
- 调度：`news.review_time=15:45` + 18:30 重试；盘中事件独立低频检查（仅 P0/P1 规则命中才调 LLM）。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 变成短线情绪/资金流 | 提示词以论点/风险为目标；禁止"短期涨跌/资金流"结论；评估集拦截 |
| 自主发布出错 | 引用强制、事实/解释分层、版本化、可撤回；每周抽检；不接交易 |
| 盘中噪音 | 只 P0/P1；冷却/每日上限；规则先行，LLM 只做解释 |
| 新闻诱发频繁交易 | 交易由母策略决定；新闻不进入策略；政策只进复核清单 |
| 成本/延迟 | 1 次/日 + 事件触发；上限 30 条；缓存 |
| 来源缺失/幻觉 | `unavailable` 显式标注；无来源不写事实；不用旧闻冒充今日 |
