# 面板 UI 迭代 · P0（2026-11-19）

> 任务：**T95 · 面板结果视图**。目标是把"账户结果"放到第一屏，并把净值从
> 表格升级为可读的收益曲线；不动交易路径、不增数据库写入、不引前端依赖。
>
> 本文是 UI 迭代的**唯一契约**：先定口径和布局，再写代码；后续 P1/P2 在同一
> 文件追加，不另起一份"设计稿"。

## 1. 设计理念（现在明确的那一套）

本面板沿用 Stock Dashboard 已确立的设计语言，并对本项目加三条硬约束：

| # | 原则 | 落到本面板的具体做法 |
|---|---|---|
| 1 | **只读、真实** | 所有查询 `mode=ro`；数字只有一个口径（服务端算），前端只画；缺数据显性，不补 0、不画假线 |
| 2 | **结果优先** | 第一屏回答"钱怎么样"；过程（意图/条件单/体检）第二层；配置（方案/模型）最后层 |
| 3 | **极简线框** | 1px hairline 分割线、8px 圆角、留白优先；**不用 emoji**；阴影只作层级提示 |
| 4 | **语义色克制** | 红涨绿跌（A 股）；`--accent` 蓝只给交互与曲线；状态色只给 ok/warn/bad |
| 5 | **零依赖** | 图表用**纯 SVG** 手绘，不引入 echarts/chart.js，不新增 CDN；字体沿用现有 Inter/Noto + 系统回退 |
| 6 | **降级显性** | 无基准显示 `—`；NAV 缺日画**虚线**并标"缺 N 日"；20:50 前今日盈亏标"盘中估算"；<2 个点显示"数据不足" |
| 7 | **字体/留白不动** | 沿用当前字号、行高、1440 容器、24/16/8 间距；不重做设计系统，只重组信息 |

> 说明：现有页面里 `🔴` 等 emoji 属历史遗留，本次一并移除，改用 CSS 状态点。

## 5. 组件规格

### 5.1 KPI 条（`#cards`，沿用 `.market-row` 类名）

| 卡 | 主值 | 副行 | 口径 |
|---|---|---|---|
| 总资产 | `¥95,800` | 可用资金 + 持股市值 | `status.total_value` |
| 今日盈亏 | `−6.77`（红绿） | `−0.01%` + `盘中估算` 标签（若未收盘 NAV） | `today_pnl` |
| 累计收益 | `−4.20%` | `−4,199.61` 自 2026-09-28 | 相对 `initial_cash=100,000` |
| 最大回撤 | `6.36%` | 发生于 2026-11-19 / 当前 6.36% | 收盘 NAV 序列 |
| 仓位 | `51.8%` | 现金 46,180 | `market_value/total_value` |

- 宽度：5 列等分；≤1100px 3 列；≤720px 2 列。
- 数字 `tabular-nums`；金额两位、百分比两位；红涨绿跌。

### 5.2 收益曲线（`#perfchart`）

- **模式**：总资产（默认）/ 累计收益率 / 回撤（水下）。
- **横轴**：按日期比例（不是按序号），周末/假期自然形成间距；**缺 NAV 的交易日**
  用虚线连接，并在曲线下方标注"缺 N 日"。
- **纵轴**：总资产按金额（带初始资金 100,000 虚线）；收益率按 %；回撤从 0 向下。
- **点**：点数 ≤ 60 时画 3px 圆点；不画平滑样条（避免暗示盘中高频）。
- **悬浮**：显示日期、总资产、当日收益额/率、累计收益、回撤。
- **空态**：<2 个交易日显示"净值记录不足（至少 2 个交易日）"；接口失败显示
  "加载失败 · 重试"（不显示假曲线）。
- **覆盖度**：标题右侧徽标 `26/34 交易日`；缺日 >0 时用 warn 色，tooltip 列前 5 个缺日。
- **无障碍**：SVG 带 `role="img"` 与 `<title>` 摘要；模式按钮可键盘操作。

### 5.3 今日 / 系统卡

| 行 | 内容 |
|---|---|
| 健康 | 状态点 + `healthy / 告警 N 项`；点击展开 alert 文本（沿用 `#healthbar`） |
| 今日成交 | `3 笔（买 1 / 卖 2）`；无成交显示 `0 笔` |
| 条件单 | `9 挂 / 4 已交框架 / 今日 1 成交` |
| 意图 | `今日执行 3 / 未决 0 / 今日拒绝 0` |
| 体检 | `16 绿 / 2 黄 / 0 红` + 最近运行时间；未跑显示"今日未体检" |
| 数据 | `行情截至 2026-11-19` |

### 5.4 持仓表（增强）

列：`代码/名称 · 股数 · 可卖 · 成本 · 现价 · 市值 · 占比 · 浮盈亏 · 持仓天数 · 距峰值 · 走势`

- 占比 = 市值 / 总资产；持仓天数 = 今天 − `entry_day`（自然日，标"天"）。
- 距峰值 = `现价/peak_price − 1`，负值绿色（回撤）。
- 走势：最近 10 根日线收盘，纯 SVG 72×24，涨跌用中性灰/语义色描边。

### 5.5 净值明细

`<details>` 折叠，保留现有表格列（时间/总资产/可用资金/浮动盈亏），默认收起。

## 6. 数据契约（服务端唯一口径）

### 6.1 `GET /api/performance`

```json
{"ok": true, "data": {
  "initial_cash": 100000.0,
  "series": [{"date":"2026-09-28","total_value":99985.78,
              "ret":-0.000142,"drawdown":0.0}],
  "summary": {"total_return":-0.0420,"total_pnl":-4199.61,
              "today_pnl":-6.77,"today_pnl_pct":-0.000071,
              "mdd":0.0636,"mdd_date":"2026-11-19","current_drawdown":0.0636,
              "vol_annual":0.1175,"sharpe":-3.61,
              "win_days":10,"lose_days":14,
              "exposure":0.518,"estimated":false},
  "coverage": {"expected":34,"present":26,
               "missing":["2026-10-08"]},
  "asof": "2026-11-19",
  "definitions": "收盘 NAV；同日取最后一条；缺日不补；收益相对初始资金"}
}
```

**口径（必须与单测一致）：**

1. 同日多条 NAV 取最后一条（reset/补记会产生重复日）。
2. `ret = total_value / initial_cash − 1`（无出入金，不需要 TWR）。
3. 日收益 = 相邻**有记录**日之间；缺日不插值，跨缺口的那一天按多日收益计算，
   并在 `coverage` 显性列出。
4. `mdd = max(1 − v_i / max(v_0..v_i))`，记录发生日；`current_drawdown` 同理。
5. `vol_annual = stdev(日收益, ddof=1) × sqrt(252)`；`sharpe = mean/ stdev × sqrt(252)`（rf=0）。
6. 有效收益日 < 2 ⇒ 上述统计返回 `null`，`series` 仍返回已有点。
7. `estimated` 由 `/api/overview` 的实时值决定；`/api/performance` 本身只报收盘口径。

### 6.2 `GET /api/overview`

```json
{"ok": true, "data": {
  "date": "2026-11-19",
  "status": { "...": "同 /api/status" },
  "today_pnl": -6.77, "today_pnl_pct": -0.000071, "estimated": false,
  "fills": {"n": 3, "buy": 1, "sell": 2},
  "conditions": {"armed": 9, "queued_rq": 4, "filled_today": 1, "created_today": 0},
  "intents": {"executed_today": 3, "rejected_today": 0, "pending": 0},
  "checks": {"at": "2026-11-19T15:30:03", "green": 15, "warn": 3,
             "red": 0, "red_ids": [], "warn_ids": ["nav","raw_gate","parity_trace"]},
  "health": {"healthy": true, "alerts": [], "checked_at": "..."}
}}
```

- `today_pnl`：若最新 NAV 是今天 → `last − prev`（`estimated=false`）；
  否则**必须**有"今日价"（今日 raw 或今日分钟线）才估算 `live_total − last`
  （`estimated=true`）；没有今日价（开盘前/数据未更新）→ `today_pnl=null`，
  页面显示 `—` / `待今日行情`，**不拿昨日价算成 0**。
  `live_total`/`live_market_value`/`cash` 一并返回，供盘中让 KPI 与持仓同口径。
- `prices_ready`：是否全部持仓都有"今日价"；false 时不做今日估算。
- `checks`：读 `logs/daily_check.jsonl` 中今天的最后一条；没有则 `null`。
- 所有计数从账本只读聚合，不写库。

### 6.3 `GET /api/positions`（增字段，不破坏旧前端）

在现有字段上追加：`name`（若有）、`peak_price`、`entry_day`、`spark`（最近 10 根收盘）。
旧字段一个不改。

**P0 口径修正（2026-11-19 实测）**：面板的现价/市值/迷你走势改用
`daily_bars_raw` 的最新收盘，而不是 `get_status()` 的前复权日线。原因：
11-19 生产上 `daily_bars` 只到 **11-18**（22 只），而 NAV 收盘（raw）已到 11-19；
两者混用会让"总资产"（96,071）与"净值曲线"（95,800）在同一屏出现两个数。
raw 与账本成交价同源，按 raw 计算的持仓市值与 `nav_history.market_value`
逐分对上（实测 **49,620.0**）。`quote_asof` 一并返回，页头"行情截至"以它为准。

**11-20 盘中补充（同一原则）**：价格优先级改为
**今日 raw 收盘 > 今日分钟线 > 最近 raw 收盘**，每行返回
`price_source`（收盘/分钟）、`price_asof`、`price_time`。
盘中（raw 还没今天）用分钟线，页面在现价旁标 `10:35`；
不再让"价格实时、市值昨日"的半截数据同屏。KPI 总资产在 `prices_ready`
时用同一套价（`/api/overview.live_total`），否则回落到最后 NAV。

## 17. P2 第二项：今日分时（2026-11-21）

`GET /api/intraday?date=YYYY-MM-DD`（默认今天）返回：

```json
{"date":"2026-11-20","available":true,"fills":3,
 "reconstruction_ok":true,
 "series":[{"ts":"2026-11-20T09:30","total":95800.4,"cash":46180.4,"mv":49620.0}],
 "start":{"cash":46180.4,"positions":{"600036":200}},
 "note":"按当前账本反推当日开盘；分钟线估值，非逐笔撮合"}
```

口径：
- 从**当前账本**反推目标日：先反向应用目标日之后的成交 → 目标日收盘，
  再反向应用当日成交 → 当日开盘（持仓/现金）；
- 正序列：09:30 用上一交易日 raw 收盘估值，之后按 5 分钟线逐点估值；
  成交时间（截到分钟）≤ 当前 bar 时生效；
- `reconstruction_ok=false`（反推出负仓/负现金）时图仍画，但显式标"需核账"；
- 无分钟线（非交易日/采集未到）返回 `available=false`，页面显示"今日无分时"。

面板总览新增"今日分时"卡：纯 SVG 面积线 + 悬浮（时间/总资产/现金/市值），
标题显示点数与当日成交笔数。当前 11-21 是周六，生产接口应返回
`available=false`；下个交易日 09:35 起会有数据。

> 2026-11-21 布局调整：分时是图表，已上移到主收益曲线之后、净值明细/持仓之前。
