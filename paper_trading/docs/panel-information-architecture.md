# 量化交易盘面板信息架构（2026-11-24）

> 目的：把“看盘”从数据堆叠变成**决策顺序**——先看今天怎么样，再看钱在哪、
> 风险在哪，最后才看细节。与 `docs/ui-iteration-20261119.md` 的设计契约一致：
> 浅色/深色、红涨绿跌、hairline、零 emoji、零前端依赖、纯 SVG、指标服务端算。

## 1. 设计原则

1. **一屏回答三个问题**：今天赚/亏多少？钱押在哪？有没有需要人管的事？
2. **结果优先于过程**：NAV/盈亏/仓位永远在成交/意图之前；过程放交易页。
3. **不重复口径**：NAV 只认收盘 raw；盘中价只用于展示；同一数字只有一个来源。
4. **缺数据就空着**：`unavailable`/`stale` 显式展示，不填 0、不拿旧值冒充。
5. **能删就删**：表格默认折叠、明细延后到二级页；主视图只留会改变决策的信息。

## 2. 四个视图与优先级

| 视图 | 必须（P0） | 应该有（P1） | 可选（P2） | 砍掉/后置 |
|---|---|---|---|---|
| 总览 | 总资产、今日盈亏、累计收益、最大回撤、仓位；收益曲线；今日/系统卡；持仓表 | **CSI300 基准 + 超额**；**行业分布**；今日分时；缺口/覆盖徽标 | 持仓迷你走势；回撤分区；相对回撤 | 完整净值表（折叠保留）；逐日收益表 |
| 交易 | 订单/成交；计划 vs 执行；被拒原因 | 意图队列；条件单；已实现盈亏/胜率/费用；逐笔时间线 | 单笔归因；换手率 | 全量历史（分页/导出）；重复的 NAV 列 |
| 运维 | 心跳（engine/agent/rq_tick/minute）；daily-check 红黄；数据来源/新鲜度 | 最新计划 + freshness；**母项目契约探针**；数据质量缺口 | 影子对账；日志尾 | 原始日志全文；重复的接口审计表 |
| 控制台 | 方案切换（内置免口令）；运行时刻 | LLM 配置；自定义指令（要口令） | 手动试算/预览 | 调试开关；内部参数 |

## 3. 总览页布局（自上而下）

```
KPI 行：总资产 | 今日盈亏 | 累计收益 | 最大回撤 | 仓位
收益曲线（NAV / 累计收益率 / 回撤）
  ├─ 叠加：CSI300（sh000300）归一化曲线 + 超额曲线
  └─ 徽标：基准 asof / stale / 缺口天数
分时（今日，成交时间线 + 分钟线；周末回退最近交易日）
今日 / 系统卡：成交笔数、条件单、意图、体检、健康、已实现
持仓表：名称 / 数量 / 成本 / 现价 / 市值 / 占比 / 行业 / 止损
行业分布：按 sector 聚合的权重条形（未知单独一桶）
风险条：仓位接近上限、单票集中、回撤接近熔断、数据 stale
净值明细（折叠）
```

**为什么基准放在曲线里而不是单独一张图**：基准的唯一用途是回答“跑赢没有”，
与 NAV 同图才有意义；单独一张指数图会变成看行情，不是看组合。

**为什么行业分布放在持仓之后**：先看个股，再看集中度；行业是持仓的聚合视图，
不抢个股信息的位置。

## 4. 指标口径

| 指标 | 口径 |
|---|---|
| 总资产 / 今日盈亏 | 收盘 NAV（raw 定稿价）；盘中只展示不定稿 |
| 累计收益 | `NAV / initial_cash - 1`；同日 NAV 取最后一条 |
| 最大回撤 | NAV 序列峰值回撤；缺日虚线，不插值 |
| 仓位 | `持仓市值 / 总资产`；停牌按最近 raw 计价 |
| 基准 | `benchmark_daily` 的 `sh000300`，价格指数、不复权；与 NAV 按**同一起点**归一化 |
| 超额 | `组合累计收益 - 基准累计收益`（同日对齐；基准缺日标 stale，不外推） |
| 行业 | `stock_snapshot.sector`；NULL → “未知”；不按市值权重猜 |
| 已实现盈亏 | FIFO；卖出无匹配买入只报量、不算收益 |

## 5. 明确取舍

**保留**：NAV/盈亏/回撤/仓位、收益曲线、今日卡、持仓、成交、计划执行、数据新鲜度、
健康告警、基准、行业、已实现与费用。

**折叠**：净值明细、AI 流水、意图/条件单全量、数据来源明细。

**后置**：因子/风格暴露、逐笔归因、盘口/逐笔、新闻流、宏观面板、复杂筛选器。

**删除**：重复的净值表、装饰性图表、任何 emoji、前端图表库。

## 6. 验收

- 715px 窄屏无横向溢出；浅色/深色各一张截图；
- 总览首屏能回答“今天怎么样/钱在哪/有没有告警”；
- 基准与行业均带 `asof/stale/unavailable`，母库缺数据时不显示假曲线；
- 所有指标由服务端计算，前端只做 SVG 绘制。
